# ICICI LAIP Form

A Next.js contact form app for Webflow Cloud.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Webflow Cloud

1. Push this repo to GitHub
2. In Webflow → Site Settings → Webflow Cloud → open your environment
3. Click "Deploy latest commit"

## Project Structure

```
app/
  layout.tsx   # Root layout
  page.tsx     # Contact form page
next.config.js # Webflow Cloud edge config
package.json
tsconfig.json
```
